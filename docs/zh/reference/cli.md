# CLI 完整命令与参数手册

K0maru CLI 所有子命令、参数选项、环境变量与退出码参考。

## 命令一览

- `k0maru loadout`：生成项目启动上下文
- `k0maru search`：执行混合检索
- `k0maru offload`：提取与脱敏终端日志
- `k0maru inspect`：查询与导出已脱敏日志节点
- `k0maru sync`：强制同步并重建索引
- `k0maru flush`：将决策记录写入 Markdown
- `k0maru distill`：提取错误日志为技能草案
- `k0maru install`：一键配置智能体客户端
- `k0maru doctor`：环境自检
- `k0maru ui`：启动暗黑控制台 WebUI
- `k0maru mcp`：启动 FastMCP Stdio 服务
