# 3-Minute Quickstart

Experience the end-to-end memory management and self-healing lifecycle across five streamlined stages.

## End-to-End Workflow

1. **Verify Environment**: `k0maru doctor`
2. **Bootstrap Context**: `k0maru loadout --copy`
3. **Offload Terminal Traces**: `k0maru offload < cargo-build.log`
4. **Recall Memory**: `k0maru search "sqlite concurrency lock"`
5. **Crystallize Decisions**: `k0maru flush --title "Fix WAL Concurrency" --tag bugfix`
