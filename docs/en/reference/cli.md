# CLI Subcommands & Flags

Comprehensive reference for all K0maru CLI subcommands, options, environment variables, and exit codes.

## Available Subcommands

- `k0maru loadout`: Generate compact system bootstrap context
- `k0maru search`: Perform hybrid retrieval over notes and codebases
- `k0maru offload`: Sanitize and compress verbose compiler traces
- `k0maru inspect`: Query and export offloaded trace nodes
- `k0maru sync`: Force incremental scan and cache index sync
- `k0maru flush`: Persist structured decisions into Markdown notes
- `k0maru distill`: Heuristically synthesize failure logs into skills
- `k0maru install`: Automated one-click client configuration
- `k0maru doctor`: System environment and dependency diagnostics
- `k0maru ui`: Start the Developer Dark Cockpit WebUI
- `k0maru mcp`: Launch FastMCP JSON-RPC server over stdio
