# 智能体生态挂载

K0maru 通过 `k0maru install` 提供一键智能体集成能力。

## 支持的客户端与智能体

- **Claude Code** (`~/.claude.json`)
- **Cursor** (`~/.cursor/mcp.json`)
- **Windsurf** (`~/.codeium/windsurf/mcp_config.json`)
- **Gemini CLI / Antigravity**
- **Cline / Roo Code**
- **Nous Hermes Agent** (`~/.hermes/skills/`)
- **OpenClaw**
