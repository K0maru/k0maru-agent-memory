# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The K0maru team takes security vulnerabilities seriously.

If you discover a security issue or vulnerability in `k0maru-agent-memory`:
1. **Do not create a public GitHub issue**.
2. Report the vulnerability privately via GitHub Private Vulnerability Reporting: [Submit Security Advisory](https://github.com/K0maru/k0maru-agent-memory/security/advisories/new).
3. Include:
   - Description of the vulnerability and attack vector.
   - Minimal reproducible proof of concept or commands.
   - Potential impact on local files, vaults, or credentials.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
