# FastMCP Stdio Protocol Contracts

Specification of K0maru's six native FastMCP tools exposed over standard input/output.

## Native FastMCP Tools

1. `get_project_loadout`: Fetch compact system bootstrap context
2. `recall_memory`: Execute hybrid retrieval over notes
3. `offload_context`: Sanitize and distill terminal logs into state machines
4. `inspect_log_node`: Query details for an offloaded log node
5. `flush_session`: Persist structured insights to Markdown
6. `distill_session_skill`: Distill error patterns into reusable skills
