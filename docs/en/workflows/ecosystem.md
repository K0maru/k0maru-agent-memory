# Agent Ecosystem Integration

K0maru integrates seamlessly with leading AI coding agents through the `k0maru install` command or manual MCP configuration.

## Supported Clients & Runtimes

- **Claude Code** (`~/.claude.json`)
- **Cursor** (`~/.cursor/mcp.json`)
- **Windsurf** (`~/.codeium/windsurf/mcp_config.json`)
- **Gemini CLI / Antigravity**
- **Cline / Roo Code**
- **Nous Hermes Agent** (`~/.hermes/skills/`)
- **OpenClaw**
