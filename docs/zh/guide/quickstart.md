# 3 分钟极速起步

按照以下 5 个阶段快速体验 K0maru 的端到端记忆管理与自愈工作流。

## 极速闭环体验

1. **环境检查**：`k0maru doctor`
2. **生成引导上下文**：`k0maru loadout --copy`
3. **符号化日志脱敏与压缩**：`k0maru offload < cargo-build.log`
4. **混合语义召回**：`k0maru search "sqlite concurrency lock"`
5. **记忆沉淀结晶**：`k0maru flush --title "Fix WAL Concurrency" --tag bugfix`
