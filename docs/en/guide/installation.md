# Installation Guide

K0maru provides several installation channels, including automated shell installation, Homebrew, Cargo crates.io, and pre-compiled release binaries.

## Automated Install Script

```bash
curl -fsSL https://raw.githubusercontent.com/K0maru/k0maru-agent-memory/main/install.sh | bash
```

## Verify Installation

```bash
k0maru doctor
```
